# حزمة تدقيق ميزانية التوليد والدقة

هذه الحزمة تعيد حساب نتائج التجربة الرئيسية على المعالج فقط، دون تحميل النموذج
أو إعادة التوليد. تضم **32,000 توليدة، 500 مسألة، أربع ميزانيات، و16 محاولة لكل
مسألة وميزانية**، بالنموذج `l3lab/L1-Qwen-1.5B-Exact`.

النسخة الموسعة تضيف تجارب الصيغ على النموذجين **1.5B و7B**: تجربة شاملة
بـ520 توليدة، وأخرى لمقارنة خمس صيغ بأمثلة موحدة بـ200 توليدة. تتضمن بيانات
إعادة حسابهما ونتائجهما وبرومبتاتهما والكود الأصلي.

| الميزانية المطلوبة | الصحيح من 8,000 | الدقة المعتمدة |
| ---: | ---: | ---: |
| 512 | 5,533 | 69.1625% |
| 1,024 | 6,163 | 77.0375% |
| 2,048 | 6,419 | 80.2375% |
| 3,600 | 6,642 | 83.0250% |

الأحكام محفوظة: 31,567 بقواعد آلية، و405 بتحكيم ذكاء اصطناعي، و28 بتحكيم بشري.
لا توجد أحكام معلقة، لكن هذا لا يعني أن كل الأحكام راجعها بشر.

## التشغيل

من داخل المجلد المستخرج، باستخدام Python؛ البيئة المرجعية هي 3.11.4:

```sh
python -m pip install -r requirements.txt
python verify_release.py
python reproduce.py --output outputs/run-001
```

في كولاب اختر معالج CPU، وارفع ملف ZIP وفكّه وانتقل إلى مجلد `l1-budget-audit`،
ثم شغّل الأوامر السابقة مع إضافة `!` في بدايتها. يحتاج تثبيت المكتبات إلى الإنترنت؛
بعدها يعمل الحساب دون اتصال. قد تختلف نسخة بايثون في كولاب عن البيئة المرجعية.

ستجد تقرير المطابقة في `outputs/run-001/reproduction-check.json`.
القيمة `passed` تعني تطابق الحسابات العلمية والجداول الستة مع المرجع المحفوظ،
وكذلك مطابقة تحليلات تجربتي الصيغ مع نتائجهما المؤرشفة.
يعاد رسم خمسة أشكال بصيغتي PNG وPDF. لكل تشغيل اختر مجلدًا جديدًا؛ لا تستبدل
الحزمة أي نتائج سابقة.

## حدود الحزمة

الحزمة تشمل تحليل التجربة الرئيسية والأطوال والتداخل وتجربتي الصيغ على النموذجين.
الصيغ السبع هي CoT وBeConcise وOnlyNumbers وNoProperGrammar وNoCoT وCoD وSoT؛
جُرّبت CoT بدون أمثلة وبثمانية أمثلة، ولذلك صار عدد شروط الصياغة ثمانية.
تفاصيلها في [ملف التجارب](docs/format-pilots.md).

النصوص الخام ومعرفات التوكنز الأصلية غير مرفقة، ولذلك يعاد حساب الإحصاءات من
القياسات والأحكام المحفوظة. الكود الأصلي لتجارب الصيغ محفوظ كتوثيق؛ إعادة
الاستدلال والتحكيم تتطلب بيئة التوليد والنصوص الأصلية. الأحكام المعلقة في
التجارب الاستكشافية تبقى معلقة، ولا تُخلط مع الأحكام النهائية للتجربة الرئيسية.

الميزانية تعليمة في البرومبت وليست إيقافًا قسريًا للتفكير. الحد الأعلى للمخرجات
كلها 6,000 توكن. الأطوال قبل نهاية التفكير تختلف عن إجمالي أطوال المخرجات،
و39 توليدة بلا حدّ نهاية تفكير محسوم؛ لم نعوّض أطوال تفكيرها بتخمين.
